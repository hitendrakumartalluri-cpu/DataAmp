# AMP 0.10.0 Beta 1

AMP 0.10.0 is the first connector-only enterprise content intelligence Beta. It preserves native storage APIs and treats AWS S3, Azure Blob, Hitachi HCP, HCP S3 and VSP One Object as authoritative systems.

## Product workflows

- HCI-familiar Connections, Pipelines, Indexes, Search and Monitoring navigation
- connector discovery and event capture separated from index projection
- full-text extraction with deterministic object identity
- federated query routing, per-index aliases and result consolidation
- configurable age, type, platform, lifecycle and duplicate analytics
- user-defined regex PII rules with masked evidence
- priority-ordered retention, object-lock and legal-hold planning
- storage/catalogue/index/AI reconciliation and missing-object reporting

## Safety boundary

The Beta governance executor is intentionally plan-only. `DRY_RUN` and `PLAN` produce auditable actions but never mutate a source object. Native retention and hold execution requires a connector-specific capability adapter, credentials, conflict checks and production validation.

## Runtime boundary

The bundled local projection simulates a Solr-compatible search plane for zero-dependency evaluation. External Solr, cloud storage authentication and HCP/VSP One appliance certification remain deployment integrations, not emulated claims.
