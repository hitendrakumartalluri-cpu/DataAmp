# Glossary

| Term | Meaning |
|---|---|
| AMP | Archive Modernization Platform, branded DataAmp |
| Catalogue Group | Administrative catalogue for exactly one storage system plus container |
| recon ID | Stable container-local UUIDv5 identity for a logical object |
| Virtual shard | Stable hash partition used to route catalogue records |
| Generation | A bounded discovery observation cycle |
| Tombstone | Retained evidence that a previously observed object is absent/deleted |
| Hydration | On-demand copy from legacy/source storage into the primary/target |
| Sidecar | Rich metadata or annotation object stored beside the payload package |
| Backend authority | Rule that storage owns native versions and compliance enforcement |
| HOP | Apache Hop pipeline engine used for storage-direct indexing workflows |
| RRF | Reciprocal Rank Fusion for combining ranked result sets |
