# Gateway Beta Archive

The client-facing gateway was retired from active AMP development on 2026-09-24 after the product was narrowed to indexing, search, analytics and governance.

The complete implementation—including HCP REST and S3 front doors, gateway routes, response policies, managed packages, sidecar paths, migration/hydration code, UI, tests and documentation—is preserved at:

- Branch: [`archive/gateway-beta-2026-09-24`](https://github.com/hitendrakumartalluri-cpu/DataAmp/tree/archive/gateway-beta-2026-09-24)
- Final source commit: `3799ab8700dc52ffa0548477d1672d21a7953951`

The Wiki sync workflow preserves the pre-retirement Wiki on the matching archive branch before publishing the generated connector/indexing documentation.

Gateway issues were closed as `not planned` and point to this archive. Historical changelog and acceptance evidence may still mention the gateway because they describe executed Beta tests; those records are not statements of current product scope.
